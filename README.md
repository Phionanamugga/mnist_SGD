
# 🚀 Stochastic Gradient Descent (SGD) - A Comprehensive Exploration

## 📌 Overview
This project provides an in-depth exploration of **Stochastic Gradient Descent (SGD)** and its variations, applied in different machine learning tasks. It includes:
- Basic concepts of **SGD**
- **SGD in linear & logistic regression**
- **SGD for deep learning** (neural networks)
- **Regularization techniques**
- **Learning rate schedules**
- **Comparison with other optimizers**

This repository is designed to **demonstrate mastery of SGD** through well-structured **code, experiments, and tests**.
